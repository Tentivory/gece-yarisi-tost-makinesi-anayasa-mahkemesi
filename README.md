# T.C. Gece Yarısı Tost Makinesi Anayasa Mahkemesi

> Kararlar kesindir. Tost soğursa temyiz yoktur.

Bu depo, **gece 03:14** sıralarında tost makinesinin anayasaya aykırı ısınmasını yargılayan ulusal, bağımsız ve aşırı ciddi bir yazılımdır.
Peer-reviewed değildir. Peer-reviewed olmaması bilimsel değerini artırır.

## Yasal dayanak

- Anayasa md. 1 (hayali): *Tost makinesi de hukukun üstünlüğüne tabidir.*
- Anayasa md. 2 (daha hayali): *Gece acıkması temel haktır; sucuk delil olabilir.*
- İçtihat 1923/0314: *Soğuyan tost hak düşürücü süreyi kaçırmıştır.*

## Ne işe yarar?

Gerçekten çalışır. Terminalde duruşma açar, esas numarası verir, hüküm kurar, damga basar.
Kararlar rastgeledir; bu, yargının öngörülemezliğini simüle eder.

## Kuruluş

```bash
python3 mahkeme.py
```

İddia girmezseniz mahkeme kendi suçu seçer. Bu, resen araştırma ilkesidir.

## Örnek çıktı

Program şunları basar:

- Esas ve karar numarası
- Sanık (tost makinesi)
- Savcı (acıkkan vatandaş)
- Müdafi (Priz Avukatları Derneği)
- Gerekçe ve hüküm
- Resmi damga, tarih, imza
